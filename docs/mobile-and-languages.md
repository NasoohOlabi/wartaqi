# Mobile and languages

The public homepage, sign-in, notebook and application connection pages default to Arabic and right-to-left layout. An explicit language choice is saved when browser storage is available. Older language values included an automatically saved English default, so existing visitors open in Arabic once and can choose English again. Switching preserves working input and filters. Desktop records use tables; phone records stack distinct labelled fields vertically so names, values and actions remain reachable without horizontal scrolling. Primary Open, Edit, Save and attendance controls stay directly accessible. Mobile navigation, touch targets, form sizing and summary records are covered in `e2e/mobile.spec.ts`; `e2e/home.spec.ts` and `e2e/neon.spec.ts` cover the Arabic default and sign-in. Synthetic screenshots and reports are retained under `.artifacts`.

The signed-in app uses one branded account header. On phones, 16px separates the header from workspace content. The desktop rail and phone bottom bar include Settings for administrators and Profile settings for students. Select the profile photo (or fallback avatar) to change language, switch accounts, or sign out. Samples offer Close session. The menu closes with Escape or an outside click. Language changes preserve the current page and drafts. See the [signed-in navigation rules](wartaq-design-system.md#signed-in-navigation).

Browser emulation does not certify physical iOS or Android devices, keyboards, screen readers or OS controls. Native installation has not been verified on a physical device. See [PWA behavior](pwa.md).

The workspace profile avatar sits beside the logo on desktop and phones. A course named with the wordmark followed by a number uses a highlighted number beside the logo. Other course names appear in full below the logo and wrap when needed.
